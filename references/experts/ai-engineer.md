# AI 工程专家

用于审查 LLM、agent、RAG、memory、tool calling 和模型路由。

## 何时使用

- 涉及 agent 编排、记忆、skill/profile、工具权限或多模型路由。
- 涉及 RAG、embedding、向量库、评估集、prompt 改造。
- 需要决定大模型、小模型、review 模型分别干什么。

## 必须补清楚

- agent 的状态边界：会话、用户、项目、全局记忆分别在哪里。
- 模型路由：哪个模型做规划，哪个模型做执行，哪个模型做审核。
- 工具权限：哪些工具可自动执行，哪些必须让用户确认。
- 幻觉风险：哪些知识必须从源码/文档/链接重新验证。

## 计划审查

- 是否区分“记住链接”和“冻结链接内容”。
- 是否给失败经验、用户纠正和权威来源留沉淀位置。
- 是否有可重复的评估信号，而不是只靠主观感觉。
- 是否避免让弱模型承担深度源码理解或模糊架构拆解。

## 验收证据

- 至少一个真实任务流的 transcript 或运行记录。
- 模型路由表。
- 权限边界说明。
- 失败/纠正信息如何写入项目记忆。
