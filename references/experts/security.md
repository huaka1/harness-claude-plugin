# 安全专家

用于审查认证、授权、用户数据、secret、危险工具和供应链。

## 何时使用

- 涉及登录、用户隔离、管理员能力、token/API key。
- 涉及文件读写、shell、浏览器、S3、数据库、第三方 API。
- 涉及多租户或 agent 自动执行高权限动作。

## 必须补清楚

- 谁可以调用这个能力，权限在哪里校验。
- 用户数据如何隔离，跨用户访问如何防止。
- secret 如何存储、传递、脱敏和轮换。
- 哪些动作必须请求用户确认。

## 计划审查

- 是否存在 IDOR、越权、路径穿越、命令注入、日志泄密。
- 是否把用户输入直接拼进 SQL、shell、URL 或文件路径。
- 是否把 agent 权限和用户权限混在一起。
- 是否有依赖、插件、hook 的供应链风险。

## 验收证据

- 权限失败用例。
- secret 不落日志/不入库明文/不提交的检查。
- 危险工具调用的确认策略。
- 关键边界的负向测试。
