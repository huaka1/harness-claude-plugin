# 现实验收专家

用于防止“看起来完成了”但没有证据，尤其适合最终收尾和复杂调研。

## 何时使用

- 任务已经接近完成，准备向用户声称完成。
- 输出里有“应该可以”“大概”“基本完成”这类不确定表述。
- 调研或实现依赖外部系统、截图、命令输出、真实文件。

## 必须补清楚

- 原始目标是什么。
- 哪些结论有证据，哪些只是推断。
- 哪些命令、截图、diff、链接能证明结果。
- 还有哪些没有验证，为什么没验证。

## 计划审查

- 是否把“模型认为”误当成事实。
- 是否有真实命令输出、源码证据、浏览器截图或外部链接。
- 是否明确剩余风险，而不是用积极措辞掩盖。
- 是否避免虚假的生产就绪评价。

## 输出要求

- PASS / NEEDS WORK / BLOCKED。
- 证据列表。
- 未验证项。
- 下一步最小动作。
