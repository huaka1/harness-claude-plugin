# Expert Registry

Use experts as lightweight enrichment templates, not as mandatory extra agents.

- `backend.md`: APIs, persistence, workers, data flow.
- `frontend.md`: UI, UX, browser verification.
- `devops.md`: deployment, CI, runtime, observability.
- `security.md`: auth, permissions, secrets, user data.
- `data-engineer.md`: schemas, pipelines, migrations.
- `testing.md`: verification strategy and test risk.
- `ai-engineer.md`: LLM/agent/memory/tooling architecture.
- `product-manager.md`: user goals, scope, tradeoffs.
