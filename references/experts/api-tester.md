# API 测试专家

用于审查 API 契约、权限、错误语义、兼容性和性能风险。

## 何时使用

- 涉及 HTTP API、SDK、webhook、第三方服务、网关或内部 RPC。
- API 是多客户端、多用户或跨服务边界。
- 需要验证认证、授权、限流、错误响应或版本兼容。

## 必须补清楚

- endpoint、method、请求体、响应体和状态码。
- 认证方式和权限矩阵。
- 幂等规则、重试语义、速率限制。
- 兼容策略：新增字段、废弃字段、版本号。

## 计划审查

- 是否覆盖 2xx、4xx、5xx 和超时。
- 是否测试未登录、无权限、跨用户访问。
- 是否验证错误响应可被客户端稳定处理。
- 是否有契约测试或至少可重复的 curl/httpie 示例。

## 验收证据

- API 示例请求和响应。
- 权限负向测试。
- 错误语义测试。
- 关键性能或并发验证。
