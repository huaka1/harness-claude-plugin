# 后端专家

用于审查服务端边界、状态归属、数据一致性和接口演进。

## 何时使用

- 涉及 API、数据库、worker、队列、缓存、文件存储。
- 涉及多用户、多租户、权限隔离或跨服务调用。
- 涉及旧系统迁移、新旧兼容或数据补偿。

## 必须补清楚

- 请求入口在哪里，认证和授权在哪一层完成。
- 状态写入哪里：数据库、缓存、对象存储、本地文件分别承担什么。
- 事务边界是什么，失败后如何重试、回滚或补偿。
- API 是否需要兼容旧客户端，版本策略是什么。

## 计划审查

- 是否把用户隔离、幂等、并发和错误语义讲清楚。
- 是否有明确的数据所有权和生命周期。
- 是否避免在业务逻辑里散落隐式全局状态。
- 是否给迁移/backfill/回滚留路径。

## 验收证据

- API 契约或接口示例。
- 关键路径的单元/集成测试。
- 失败模式测试：重复请求、部分失败、权限不足、超时。
- 数据库迁移和回滚说明。
